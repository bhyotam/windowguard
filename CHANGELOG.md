# Changelog

## 2.0.0

- Native settings window with Displays, Applications, and General tabs.
- Configurable blocked displays and preferred destination.
- Executable-based exception and inclusion lists.
- Adjustable polling, partial-overlap handling, and oversized-window resizing.
- Per-user settings, atomic saves, and optional startup at sign-in.
- Safe defaults for new installations, disconnected monitors, and mirrored displays.
- Automated policy/configuration tests and a Windows build workflow.
- Recovery when display detection or the notification area is temporarily unavailable.

## 1.0.0

- Initial single-purpose tray utility for an audio-only display.
